# Database: PostgreSQL + Alembic
Dated 2026-09-01. Replaces: nothing.

## Decisions
- **Every schema change is a model edit plus an autogenerated, reviewed migration; never create_all.**
  Reason: model/migration drift once made a NOT NULL column silently block every insert in production.
  Silent default: `alembic revision --autogenerate -m "<what>"`, read the diff, commit both.
  Check: `alembic check` exits 0 and `alembic heads` prints one line.
- **Exactly one process runs `alembic upgrade head` at boot: the web app.**
  Reason: two containers racing migrations with no lock.
  Silent default: entrypoint runs migrations only when RUN_MIGRATIONS=1; compose sets it on the app service only (boot order is docker-compose-stack's rule).
  Check: `python scripts/check_compose.py`.
- **Every ForeignKey column is indexed.**
  Reason: one unindexed FK among three indexed ones.
  Silent default: `index=True` on every ForeignKey column.
  Check: `pytest tests/test_schema.py::test_fk_indexed`.
## Layout
app/models.py · alembic/versions/ · start.sh (migration gate)

## Not covered
Volumes, ports, and stack boot (docker-compose-stack). Test database lifecycle (tests-fastapi-postgres). Job status semantics (background-jobs).
